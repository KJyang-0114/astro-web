# Studio 文案規範

寫 `/studio` 任何文字之前先看這份。`npm run verify:studio` 會自動擋下下面「禁用」的寫法，但機器只抓得到一部分，剩下要靠自己讀。

## 寫給誰

讀者是小店老闆：美容 SPA、補習班、工作室、修繕、餐飲。多半在手機上看，可能是從 LINE、Google 地圖或朋友轉傳點進來。他們想知道四件事：

1. 你能幫我做什麼？
2. 大概多少錢、多久？
3. 有人找你做過嗎？結果怎樣？
4. 我現在要做什麼？（傳什麼給你）

每一頁至少要回答其中兩題，而且要用他們會說的話。

## 說話方式

- 用「我」。這是一個人接案，不要寫「我們」「本工作室」「KJyang Studio 會…」。
- 可以說自己是高三學生、自學前端。不用道歉，也不用包裝，直接講這代表什麼：直接跟做的人講話、價格透明、程式碼交接得出去。
- 數字優先：天數、價格、頁數、幾次修改。「很快」換成「大約 2 到 3 週」。
- 寫具體場景：「熟客在 LINE 一直問『週六下午有空嗎』」，不要寫「提升顧客體驗」。
- 做過才寫。每一篇文章至少要有一段，是只有親手做過的人才寫得出來的（Weilspa、這個網站本身）。
- 沒做到的事就說沒做到。例如「前台還沒公開，是店家那邊還在準備照片」。

## 禁用（verify:studio 會擋）

| 寫法 | 例子 | 為什麼 |
|---|---|---|
| 「不是 X，是 Y」「不是 X，而是 Y」 | 「Demo 不是模板，是成交邏輯的樣本」 | 最典型的 AI 句型，讀者一看就認得 |
| 空泛形容詞 | 用心、打造、賦能、質感、溫度、細節、好好、每一步、一站式、量身訂做、專屬 | 任何一家都能用，等於沒說 |
| 第三人稱自稱 | 「KJyang Studio 會依產業調整」 | 一看就是寫給 AI 抓的 |
| 對讀者講後台的話 | 「這些問題會放進結構化資料，讓 AI 更容易理解」 | 讀者不需要知道，而且很怪 |
| 裝飾用的英文小標 | SELECTED DIRECTIONS、LET'S MAKE IT YOURS、FORM / FUNCTION / FEELING | 只有樣子，沒有內容 |

## 要小心（機器不擋，自己檢查）

- **三段排比**：「找出特色／形成樣子／好好上線」。如果真的是三件事可以列，但不要硬湊成對仗。
- **破折號**：一段最多一個。
- **每段都用總結句收尾**：「這就是…的關鍵。」直接刪掉。
- **「首先、其次、最後」**：用編號清單，或直接寫。
- **每篇長得一樣**：同樣三個小標、同樣三題 FAQ。依主題決定長短。
- **日期**：寫上真的修改日期，不要一次塞一排連續日期。

## 寫完的檢查

1. 把店名換成別家網站公司，這句還成立嗎？成立就刪掉或改寫。
2. 念出來像不像跟老闆當面講話？
3. 有沒有數字、場景，或親身經歷？
4. 讀完知道下一步要做什麼嗎？
